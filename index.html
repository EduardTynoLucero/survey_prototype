Encuestas internas y externas con envío real por WhatsApp

El servidor guarda las encuestas, ejecuta el JOB mensual y manda el enlace individual a cada doctor. La vista previa es la encuesta real.
Sistema privado Constructor de encuestas Asistente de 5 pasos, editor tipo Forms, agenda, envíos por WhatsApp y respuestas en vivo. Vista pública Responder encuesta La encuesta tal como la abre el doctor desde el enlace de WhatsApp.
Para que funcione el envío por WhatsApp
  1. Abra una terminal en esta carpeta y ejecute cd server y npm install (solo la primera vez).
  2. Ejecute npm start y entre a http://localhost:3000/privado/
  3. Vaya a WhatsApp en el menú y escanee el QR con el número +502 4639 8632.
  4. En Envíos pulse Ejecutar ahora: los enlaces llegan a +502 3076 9579.
  5. Responda desde el celular y vea las respuestas en Respuestas.
